# Changelog

Все заметные изменения Voctarium документируются в этом файле.

## [0.3.0] — 2026-07-26

### Добавлено

- Встроенный аудиоплеер на странице результата.
- Waveform с перемоткой и кэшированием пиков.
- Синхронная подсветка предложений и переход к таймкоду по клику на текст.
- Воспроизведение исходных аудиофайлов и извлечение аудиодорожки из видео.
- HTTP Range для плавной загрузки и перемотки медиа.
- API для исходного медиа, аудиодорожки, waveform и синхронизации readable-текста.

### Улучшено

- Формирование читабельного текста теперь сохраняет структуру абзацев и таймкоды предложений.
- Обновлен интерфейс страницы результата и его поведение на разных размерах окна.
- Добавлено кэширование производных аудио-артефактов и их очистка вместе с задачей.
- Размер основного Windows-архива уменьшен: Torch, Transformers и CUDA вынесены в ML runtime, устанавливаемый при первом запуске.
- Модели `faster-whisper` больше не входят в сборку и устанавливаются пользователем через Dashboard.
- Первый запуск теперь показывает прогресс установки ML runtime, а повторный запуск приложения блокируется без повреждения загрузки.

### Проверено

- 72 автоматических теста для API, FFmpeg-сервиса, менеджера задач, обработки текста и установки ML runtime.
